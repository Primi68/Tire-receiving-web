# Tire Receiving Web

Tire Receiving의 공개 웹/PWA 배포 저장소입니다. 실행 파일만 포함하며 실제 현장 기록은 저장소나 GitHub로 전송하지 않습니다.

## 사용

- 웹 주소: <https://primi68.github.io/Tire-receiving-web/>
- iPhone: Safari에서 웹 주소를 연 뒤 **공유 → 홈 화면에 추가**
- Android/PC: 브라우저에서 열거나 지원 브라우저의 설치 기능 사용

검수 데이터와 프리셋은 사용하는 브라우저의 로컬 저장소에만 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 삭제하기 전에는 앱의 **검수 통계 · 데이터 → 데이터 백업 파일 받기**로 JSON 백업을 저장하세요.
